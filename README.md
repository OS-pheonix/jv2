# J.A.R.V.I.S Discord Bot

## Overview
Personal AI Assistant inspired by Tony Stark's JARVIS. Built with love and dedication by OS-pheonix.

## Features
- Personal Assistant Capabilities
- Context-Aware Responses
- Memory System
- Spiritual Guidance
- Project Management
- Real-time Adaptability

## Technical Stack
- Node.js
- Discord.js
- dotenv for environment variables
- Hosted on Render

## Setup
1. Clone repository
2. Install dependencies: `npm install`
3. Create `.env` file with bot token
4. Run with: `node index.js`
